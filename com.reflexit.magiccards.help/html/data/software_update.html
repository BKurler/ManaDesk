Software updates

To get the latest version of ManaDesk, choose Help > Check for Software Updates.... ManaDesk looks for a newer version and offers to install it; restart ManaDesk when asked.

You can also download the latest version from the ManaDesk releases page and install it over the old one. Your workspace is not touched by an update.

After an update, Help > What's New... shows what changed.

Before a big update, a backup never hurts.
