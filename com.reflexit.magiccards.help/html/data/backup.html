Backups

A backup is a copy of your whole workspace — decks, collections, settings and card database — in a single .zip file named after its date and time.

Making a backup

  • By hand: File > Backup. It runs in the background.
  • Automatically: ManaDesk makes one before every card database update.

Backups go to the .backup folder of your workspace, or to the folder set in Window > Preferences > ManaDesk Preferences > File Locations.

A backup kept in the workspace is lost together with the computer. Keep your workspace on a synced drive (see Cloud sync), or copy the backups somewhere else from time to time.

Restoring a backup

  1. Exit ManaDesk.
  2. Rename your current workspace folder (for example ManaDeskWorkspace-old), to keep it just in case.
  3. Unzip the backup into a new folder with the workspace's name.
  4. Start ManaDesk on that workspace.

To get back a single deck or collection, open the zip file and copy just its file from magiccards/Decks or magiccards/Collections into the same place in your workspace, while ManaDesk is closed.
