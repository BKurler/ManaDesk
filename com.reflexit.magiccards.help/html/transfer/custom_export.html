Custom export formats

Need a format ManaDesk doesn't have — for a forum, a printed checklist, another program? Create your own. It then appears in every export list, after ManaDesk's formats.

Managing your formats

Open Window > Preferences > ManaDesk Preferences > Card Export. The page lists the export formats; select one to see an example of its output. Create, edit or remove your own formats from there.

Editing a format

The Edit Exporter dialog shows a live Preview as you type.

FieldMeaning
NameThe name shown in the export lists.
FieldsThe card fields to write, in order (for example COUNT,NAME).
MethodHow each line is built:
  • C Printf Format — a pattern such as %d %s (one % per field);
  • Java Message Format — a pattern such as {0} x {1};
  • Separated Fields / Separated with Quotes — the fields with a separator between them (,, |, a space...).
If the pattern has fewer slots than fields, the missing ones are added at the end.
HeaderA line written at the top (or between decks). ${DECK.NAME} is replaced by the deck's name. It follows the export's Generate header row option.
Sideboard HeaderA line written before the sideboard cards; leave empty for none.
FooterA line written at the end of the file.
File ExtensionThe default extension of the exported file (txt, csv...).
