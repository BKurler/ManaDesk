Archidekt

Already using Archidekt? You can bring your decks and your collection into ManaDesk easily, and send them back. There are two formats: the deck list (the text of one deck) and the collection CSV.

A deck, from Archidekt to ManaDesk

  1. In Archidekt, open the deck and export it as text (keep the set and the collector number of each card).
  2. In ManaDesk, create a new deck from the clipboard (or save the text in a .txt file and pick it), or right-click a deck and choose Import into...
  3. The format is recognized as Archidekt Deck List. Check the preview, then click Finish. See Importing cards.

A line looks like 1x Sol Ring (c21) 263 [Ramp] ^Have,#37d67a^:

A deck, from ManaDesk to Archidekt

Export the deck with Archidekt Deck List (see Exporting), open the file, copy its text, and paste it in Archidekt's import. Copies of the same printing are added up, the sideboard cards end with [Sideboard], and the extra list (tokens, emblems...) is not written. There are no columns to choose.

A collection, from Archidekt to ManaDesk

In Archidekt, export your collection as a CSV file, then import it as for any other file (the format is recognized as Archidekt Collection CSV). The columns are matched by their names:

A deck exported as CSV with only Quantity and Name is read too: the cards are found by name, with the default printing.

A collection, from ManaDesk to Archidekt

Export with Archidekt Collection CSV: the columns are Quantity, Name, Finish, Condition, Language, Scryfall ID, Edition Name, Edition Code and Collector Number. A card with no condition is written as NM. There are no columns to choose.
