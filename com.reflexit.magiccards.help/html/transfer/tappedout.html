TappedOut

Already using TappedOut? You can bring your decks into ManaDesk easily, and send them back, as a deck CSV.

A deck, from TappedOut to ManaDesk

  1. In TappedOut, export the deck as a CSV file.
  2. In ManaDesk, create a new deck from the file, or right-click a deck and choose Import into...
  3. The format is recognized as TappedOut Deck CSV. Check the preview, then click Finish. See Importing cards.

The columns are matched by their names:

TappedOut's list exports (the ones with the columns Qty, Name, Set, Set Number...) are read too: Set and Set Number give the exact printing, f in Foil is a foil (f-etch: etched), SL is Lightly Played, a language is a code such as EN or FR, and a - is an empty cell. The format is recognized as TappedOut Collection CSV.

A deck, from ManaDesk to TappedOut

Export the deck with TappedOut Deck CSV (see Exporting) and import the file in TappedOut. The sideboard is written with the board side; the extra list (tokens, emblems...) is not written. There are no columns to choose. To send a collection or a list of cards instead, export with TappedOut Collection CSV: the columns are those of TappedOut's own list export.
