Importing cards

Import a card list to create a deck or collection in one go, or to add many cards to an existing one. The list can come from the clipboard, a file, a deck website, or another app's export.

Where to start

To...Use
Create a new deck from a listFile > New > Deck, then Import from Clipboard, Import from File or Website (see Creating a deck).
Create a new collection from a listFile > New > Collection, then Import from Clipboard or Import from File (see Creating collections).
Add cards to an existing deck or collectionRight-click it in the Card Navigator, Import into...

Step 1 — the source

All the ways in lead to the same pages. Here, the New Deck wizard with a list on the clipboard:

  • Clipboard — copy the list first. Edit... shows the text and lets you change it.
  • File — Browse... to pick the file.
  • Website (decks only) — see Importing from a website.

ManaDesk recognizes the format on its own; you can still pick it in the list. Example... shows what that format looks like. The line below tells how many cards were found.

Supported formats

FormatWhat it is
Freeform TextAny deck list: 4 Lightning Bolt, 4x Lightning Bolt (M10), Lightning Bolt, lines with a Scryfall id, # comments, and a Sideboard line before the sideboard cards. This is what most websites, forums and apps produce.
ManaDesk CSV / ManaDesk CSV SemicolonThe files ManaDesk exports (see Exporting).
ManaBox CSVExports from the ManaBox app (see ManaBox).
Magic Assistant CSVCSV files with a header row, from Magic Assistant and similar programs (columns such as Name, Set, Count, Language, Collector Number...).

Step 2 — check the list

Click Next. The preview shows every card as ManaDesk understood it, before anything is imported.

  • A card is matched by its Scryfall id when the file has one, otherwise by its name, set and collector number.
  • Rows ManaDesk couldn't match show an error in red. Select the row: the zone below the table explains the problem.
  • Fix a row by editing its Name, Set, Num or Multiverse id cell. Cells ManaDesk filled in by itself show in green.
  • Auto complete using first match picks the first matching printing for every card that is still ambiguous.
  • Ignore cards with errors imports only the valid rows.

Warnings

The zone below the table also warns you when the import changes something from the file:

  • Ownership — imported cards take the ownership of their destination (see Own and virtual cards):
    • into a Standard or For Trade collection, cards the file marks as virtual become Own, and are marked as Proxy — a Proxy column appears so you can untick the genuine ones;
    • into a deck or a Wishlist/To Print collection, cards the file marks as Own become virtual.
  • Language — when the file gives a card in another language, ManaDesk uses that language's printing if the card database has it (same set). Otherwise the card is imported in English, shown with a yellow Language cell.

Click Finish to import.
