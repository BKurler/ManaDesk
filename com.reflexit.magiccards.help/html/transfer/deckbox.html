Deckbox

Already keep your cards on Deckbox? You can bring your inventory and wishlist into ManaDesk easily, and send your decks and collections back to it.

From Deckbox to your collection

  1. On Deckbox, export your inventory (or your wishlist) to a CSV file.
  2. In ManaDesk, right-click a Standard collection and choose Import into... (or create a new collection from the file).
  3. Pick the file. The format is recognized as Deckbox Inventory CSV.
  4. Check the preview, then click Finish. See Importing cards.

Important: export with the Scryfall ID column. It is what lets ManaDesk find the exact printing of every card. Without it, ManaDesk has to match each card by its name, set and number, and Deckbox does not always use the same set names, set codes and card numbers as the card database (for example Standard Showdown Promos): some cards will then show an error in the import preview, and you have to fix them there.

Deckbox's export carries each card's Scryfall ID, so ManaDesk finds the exact printing with it. Deckbox numbers old sets differently and names some sets differently, so the Edition and Card Number columns are not read when the Scryfall ID is there. An older file without the Scryfall ID is matched by Name, Edition Code (used first when ManaDesk knows it) or Edition (the set's name), and Card Number; a card it cannot match is shown in red in the preview, where you can fix its set or number.

From ManaDesk to Deckbox

Export a deck or collection with the Deckbox Inventory CSV format, or Deckbox Wishlist CSV for a wishlist (see Exporting), then import the file on Deckbox. The columns are the ones of Deckbox's own export and they are fixed: all of them are always written, you don't choose them. Promo and Textless (deprecated on Deckbox) and Printing Id and Printing Note (Deckbox's own numbers and notes) are not written.
