Deckstats

Already using Deckstats? You can bring your decks and your collection into ManaDesk easily, and send them back. There are two formats: the deck list (the text of one deck) and the collection CSV.

A deck, from Deckstats to ManaDesk

  1. In Deckstats, open the deck and export it as text (the list that has the set and number of each card).
  2. In ManaDesk, create a new deck from the clipboard (or save the text in a .txt file and pick it), or right-click a deck and choose Import into...
  3. The format is recognized as Deckstats Deck List. Check the preview, then click Finish. See Importing cards.

A line looks like 1 Lightning Bolt (SLZ) 305:

DeckstatsManaDesk
Number at the startCount
Set code between parentheses, then the collector number: (SLZ) 305The exact printing
NameName
Lines after a //Sideboard heading (or starting with SB:)Sideboard
//Maybeboard sectionNot read
Other //... lines, and # comment at the end of a lineIgnored

A line with only a count and a name is accepted too, but a file where no line has a set code and collector number is not taken for a Deckstats list (it is read as a plain text list instead).

A deck, from ManaDesk to Deckstats

Export the deck with Deckstats Deck List (see Exporting), open the file, copy its text, and paste it in Deckstats' import. Copies of the same printing are added up, the sideboard follows a //Sideboard heading, and the extra list (tokens, emblems...) is not written. There are no columns to choose.

A collection, from Deckstats to ManaDesk

In Deckstats, export your collection as a CSV file, then import it as for any other file (the format is recognized as Deckstats Collection CSV). The columns are matched by their names:

DeckstatsManaDesk
amountCount
card_nameName
set_code, collector_numberThe exact printing
is_foilFinish: foil
language, condition, comment (when the file has them)Language, Condition, Comment
Other columnsNot read

A collection, from ManaDesk to Deckstats

Export with Deckstats Collection CSV: the columns are amount, card_name, is_foil, set_code and collector_number. There are no columns to choose.
