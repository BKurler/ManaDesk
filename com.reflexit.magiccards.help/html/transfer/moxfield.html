Moxfield

Already using Moxfield? You can bring your decks and your collection into ManaDesk easily, and send them back. There are two formats: the deck list (the text of one deck) and the collection CSV.

A deck, from Moxfield to ManaDesk

  1. In Moxfield, open the deck, click More → Export, and choose Copy for Moxfield. This is the format that carries each card's printing (Copy for MTGO and Copy Plain Text only have names, and Copy for Arena uses Arena's set codes).
  2. In ManaDesk, create a new deck from the clipboard (or save the text in a .txt file and pick it), or right-click a deck and choose Import into...
  3. The format is recognized as Moxfield Deck List. Check the preview, then click Finish. See Importing cards.

A line looks like 1 Sol Ring (C21) 263 *F*:

MoxfieldManaDesk
Number at the startCount
Name (a two-faced card is written A / B)Name (A // B)
Set code between parentheses, then the collector number (CMA-30 for The List)The exact printing
*F* / *E* at the endFinish: Foil / Etched
SIDEBOARD: headingThe cards after it go to the sideboard
COMMANDER:, COMPANION:Stay in the deck
MAYBEBOARD:, CONSIDERING:Not read

A line with only a count and a name is accepted too, but a file where no line has a set code and a collector number is not taken for a Moxfield list (it is read as a plain text list instead).

If a set of your deck is not in ManaDesk's card database yet (a very recent set), the preview shows the card with an error: use Update Card Database, then import again.

A deck, from ManaDesk to Moxfield

Export the deck with Moxfield Deck List (see Exporting), open the file, copy its text, and paste it in Moxfield's Import. Copies of the same printing and finish are added up, the sideboard follows a SIDEBOARD: heading, and the extra list (tokens, emblems...) is not written. There are no columns to choose.

A collection, from Moxfield to ManaDesk

In Moxfield, export your collection as a CSV file, then import it as for any other file (the format is recognized as Moxfield Collection CSV). The columns are matched by their names:

A collection, from ManaDesk to Moxfield

Export with Moxfield Collection CSV. The columns are those of Moxfield's own export, so Moxfield's collection import accepts the file. There are no columns to choose.
