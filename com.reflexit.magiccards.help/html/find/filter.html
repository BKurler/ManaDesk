Searching and filtering

There are three ways to find cards in a list, from the quickest to the most complete:

  1. Find — jump to a card in the list without hiding the others.
  2. The quick filter bar — filter by name, type or set in one click.
  3. The filter dialog — filter by anything: colors, mana value, rules text, abilities, legality, condition...

Find

Click Find... (the magnifier in the view's toolbar). A find bar opens with a search... box: type a name, and ManaDesk selects the first card that matches. Use the up and down arrows (Previous and Next) to go through the others. Find does not hide anything.

  • W (Whole word) matches whole words only. Find is not case-sensitive.
  • At the end of the list, Find starts again from the top and says Wrap around; String not found means nothing matches.
  • Use * as a wildcard, for example Jace*.
  • Find starts from the selected card, so you can select a card by hand and search again from there.

The quick filter bar

The quick filter bar sits above the list. To show or hide it in a view, check or uncheck Show quick filter in that view's page under Window > Preferences > ManaDesk Preferences > View: ....

  • Name filter — only cards whose name contains the text (* and ? work).
  • Type filter — creatures, instants, lands...
  • Set filter — one set (start typing its name).
  • In My Cards: Own / Virtual (cards you own or not), and Decks / Collections (where they are).

When some cards are hidden by a filter, the list says so. Use Reset Filter to show everything again.

Each deck and collection keeps its own filter, and gets it back the next time you start ManaDesk. The other views (Scryfall Database, My Cards, Collector...) start with no filter. To use a filter again later, save it in the filter dialog's Save/Load Filter tab.

The filter dialog

Click Filter... in the view's toolbar, or press Ctrl+6. The dialog has tabs:

Main Filter

  • Types, Rarity, Colors — check what you want to see. In Colors: Mono-Color and Multi-Color keep one-color or several-color cards; Hybrid keeps cards with hybrid mana; And asks for all the checked colors instead of any of them; Only excludes the other colors; Identity and Extended Identity match the checked colors against the card's color identity or extended color identity instead of its color (see Color identity).
  • Numbers — mana value, power, toughness, count, prices, collector number... Each can be a single value with a comparison (>=, =...) or a range (from... to...).
  • Finish — non-foil, foil, etched.
  • For your own cards: Condition, Ownership (own / virtual) and Proxy.
  • Text search — name, type line, rules text, artist, your comment, special tags, legality, language. As you type in the Text field, it suggests keyword abilities (Flying, Deathtouch, Cascade...); the Type field suggests card types and the Special field your tags.

The Search Tips panel at the bottom of the dialog explains the search syntax for the field you are in. It is also in Filter and search syntax.

Set Filter

Choose which sets to show. Type in the box to find a set; the label shows how many sets are selected. Only show the card from the latest set keeps a single printing per card.

Set lists are in alphabetical order. To list them by release date (oldest first) instead, check List sets by release date in Window > Preferences > ManaDesk Preferences.

Location Filter (My Cards)

Only show the cards that are in the decks and collections you check.

Save/Load Filter

Save the current filter under a name, and load it again later.

Use Apply to see the result without closing the dialog, and Restore All Defaults to clear every tab.
