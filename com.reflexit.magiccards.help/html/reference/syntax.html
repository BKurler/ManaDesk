Filter and search syntax

The text fields of the filter dialog understand a small search language. The same tips appear in the dialog's Search Tips panel.

Words and phrases

TypeFinds
draw cardBoth words, in any order (words are combined with AND).
"draw a card"That exact phrase (not case-sensitive).
-flying, -"enters tapped"Excludes cards with that word or phrase.

Name: wildcards

TypeFinds
Jace*Every name starting with "Jace".
*BladeEvery name ending with "Blade".
Bo?k"Book", "Bork"... (? is exactly one character).

A name with * or ? is matched as a pattern: AND, quotes and - don't apply to it. The Find box and the quick filter's name box accept wildcards too.

Type

The whole type line is searched: Wizard, Instant, Legendary Creature. Double-faced cards match on both faces.

Rules text

TypeFinds
[flying]Cards that really have the ability Flying — not cards that only mention it (for example in Reach's reminder text). It uses the abilities Scryfall lists for each card, so it works for keyword abilities, ability words ([landfall]) and keyword actions ([scry]) alike. The Text field suggests ability names as you type.
[reserved], [game changer], [reprint], [first printing],
[showcase], [borderless], [full art], [oversized], [prerelease], [playtest], [watermark: selesnya]...		Cards that havethat trait (see the Traits column in Columns): on the Reserved List, a Commander Game Changer, areprint, a first printing, or how the printing looks. Type [ in the Text field to get the suggestions.
{T}, {G}, {2/W}...A symbol, exactly as the rules text writes it.

Symbols: colors {W} {U} {B} {R} {G}, colorless {C}, snow {S}, energy {E}, {X}, generic {0} to {20}, tap and untap {T} {Q}, hybrid {W/U}, two-generic hybrid {2/W}, Phyrexian {W/P}.

Other fields

  • Artist — the artist of the printing (reprints can have another artist).
  • Comment — your own notes.
  • Special — your special tags, for example signed. Finish, condition and proxy have their own filters.

Numbers

Number fields (mana value, power, toughness, count, prices...) take a comparison and a value (>= 3), or a range (from 2 to 4).
