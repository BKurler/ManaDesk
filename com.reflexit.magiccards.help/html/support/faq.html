Troubleshooting and FAQ

The window is a mess / a view is missing

Use Window > Reset Perspective to put every view back in its place. To open a single view, use Window > Show View.

The Scryfall Database is empty

The card database hasn't been downloaded yet. Choose File > Update Card Database, or, without internet, File > Import Card Database from File.... See Updating the card database.

A new set is missing

Update the card database: File > Update Card Database.

ManaDesk without internet

ManaDesk works without internet: your decks, collections and the card database are on your computer. What needs the web (card images not seen before, importing from a website, updating the database) is simply skipped until the connection is back.

Card images don't show

Images are downloaded the first time you see a card, which needs internet. Check that Load card graphics from the web when a card is selected is on in Window > Preferences > ManaDesk Preferences.

I can't move a card to a list

The destination is greyed with a reason. Usually it is read-only, or the ownership rules don't allow it: an owned card can't be moved into a deck or a Wishlist/To Print collection (copy it instead). See What goes where.

I can't set a card to Own (or to virtual)

A card's ownership follows its list. Move the card to the right kind of list instead: a wished card becomes Own when you move it to a Standard collection. See Own and virtual cards.

An imported card is in English instead of its language

The card database only has the other-language printings of some cards. When it doesn't have the printing in that language, the card is imported in English (shown in yellow in the preview).

macOS: "ManaDesk is damaged and can't be opened"

macOS blocks apps downloaded from the internet that aren't signed by Apple. After moving ManaDesk to your Applications folder, either run this command in Terminal:

xattr -dr com.apple.quarantine /Applications/ManaDesk.app

or try to open ManaDesk once, then go to System Settings > Privacy & Security and click Open Anyway. ManaDesk also needs Java to be installed; see the installation notes on the ManaDesk GitHub page.

How do I keep my collection safe?

Put your workspace in a cloud-synced folder (see Cloud sync) and make backups.
