Report a bug or request a feature

Found a problem, or have an idea? Tell us from inside ManaDesk.

  1. Choose Help > Report a Bug or Request a Feature....
  2. Choose Bug report or Feature request, and give it a short title.
  3. Describe it: for a bug, what you did, what you expected and what happened instead; for a feature, what you would like and what it would help you do. The description is limited to 1000 characters, so the report fits in an email; the count under it shows how many are left.
  4. For a bug, keep Include the ManaDesk log checked: it helps a lot (see The log file below).
  5. Send it with Open on GitHub or Report via Email.

The ManaDesk, Java and operating system versions are always included, on one line — nothing personal. The dialog stays open after the GitHub page or the email opens, so nothing is lost if you cancel there.

Open on GitHub

Your browser opens the report on ManaDesk's GitHub page, already filled in. Attach the log file in the Log file box, review the report and click Submit. This needs a free GitHub account.

Report via Email

No GitHub account needed: a new email to the developer (BKurler-Manadesk@outlook.com) opens, filled in. Attach the log file, review the email and send it.

  • Type your address in Your email (ManaDesk remembers it). With a Gmail or Outlook.com / Hotmail address, the email opens in that webmail, in your browser; otherwise it opens in your mail app.
  • If no mail app is set up on your computer (email links open in a browser, or in nothing), ManaDesk tells you first and offers to type your webmail address instead.

The log file

For a bug, ManaDesk prepares its log as a file, ManaDesk-log.txt: the recent part of the log, with your home folder hidden. When you send the report, ManaDesk puts the file in the clipboard and opens its folder, then opens the GitHub page or the email. To attach it:

  • paste it with Ctrl+V (in the GitHub Log file box, or in the email), or
  • drag it from its folder, or from the dialog: it is shown under the checkbox, with Show in folder and Copy.

On GitHub, the attached file shows as a link to ManaDesk-log.txt: that's expected.

Copy puts the whole report, with the most recent log errors, in the clipboard, to paste it anywhere.

You can follow your report, and any question about it, on ManaDesk's GitHub issues page.
