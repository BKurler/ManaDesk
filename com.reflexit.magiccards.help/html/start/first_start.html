First start

The first time you start ManaDesk, it asks two things: where to keep your data, and whether to download the card database.

1. Choose your workspace

The workspace is the folder where ManaDesk keeps everything: your decks, your collections, your settings and the card database. By default it is ManaDeskWorkspace in your home folder.

Recommended: choose a folder inside a cloud-synced drive (OneDrive, Google Drive, Dropbox, iCloud Drive...). Your collection is then protected if your computer is lost or broken. See Cloud sync.

If you don't want to see this dialog at every start, check Use this as the default and do not ask again. To get it back later, check Show workspace selection dialog at startup in Window > Preferences > ManaDesk Preferences.

2. Download the card database

ManaDesk uses the card data published by Scryfall. On a new workspace, ManaDesk offers to download it. The download and the setup take about a minute, in the background — you can keep using ManaDesk while it runs.

No internet connection? Download the Scryfall Default Cards bulk file on another computer and use File > Import Card Database from File.... See Updating the card database.

3. What's New

After an upgrade, ManaDesk shows once what is new in that version, and adds the tabs of any new view. You can open it again any time with Help > What's New....
