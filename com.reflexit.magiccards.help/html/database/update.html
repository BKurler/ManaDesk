Updating the card database

ManaDesk's card database comes from Scryfall: every card, every printing, with images, rulings, legality and prices. Update it now and then to get the new sets, the latest legality changes and fresh prices.

Update Card Database

Choose File > Update Card Database (also in the Scryfall Database view's menu).

  • The update runs in the background, with its progress at the bottom of the window. You can keep working, or cancel it.
  • A complete update takes about a minute.
  • Before updating, ManaDesk makes a backup of your workspace (see Backups).
  • Your decks and collections are not changed: only the card data is refreshed.

Check for Card Updates

File > Check for Card Updates... tells you whether Scryfall has newer data than yours. ManaDesk can also check at every start: Check for new cards on startup in Window > Preferences > ManaDesk Preferences.

Without internet: Import Card Database from File

On a computer without internet access:

  1. On another computer, go to Scryfall's bulk data page and download the Default Cards file.
  2. Copy it to the offline computer.
  3. In ManaDesk, choose File > Import Card Database from File... and pick the file (.json, .jsonl or .jsonl.gz).

Missing data

If part of the card data is missing (for example after an interrupted update), ManaDesk notices it at startup and repairs it in the background.
