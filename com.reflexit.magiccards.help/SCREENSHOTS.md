# ManaDesk help - screenshots

Every image used by the help pages, with how to capture it. Use it when a window changes: find the
images of that window here, retake them with the same setup and overwrite the file.

- Files are in `html/images/`, PNG, referenced by the pages as `../images/<file>`.
- Window at a normal size (about 1280x800), default light theme.
- **Setup** says which data to show; any of your own decks / collections works.
- Keep each file name: the pages use it.
- Only features enabled in the app are documented (and shown).
